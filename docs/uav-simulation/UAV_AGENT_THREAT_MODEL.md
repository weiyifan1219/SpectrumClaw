# 无人机任务智能体威胁模型

## 资产与信任边界

| 资产 | 信任边界 | 主要控制 |
| --- | --- | --- |
| PX4/Gazebo 仿真状态与飞控桥 | 仅服务器端 `UavMissionService` 可写 | 任务模板、策略门控、仿真范围检查 |
| 浏览器手动飞控 | 用户显式启用的低延迟桥 | WASD 优先，接管清除智能体导航目标 |
| DeepSeek 任务提案 | 不可信文本输入 | 确定性编译器复核，模型不可直控工具 |
| MCP Host | 外部调用方 | 默认本地 `stdio`、工具白名单、认证网关要求 |
| 任务工件和审计 | 每任务独立目录 | 允许文件列表、路径约束、原子写入、`run_id`/`trace_id` |

## 威胁、缓解与剩余风险

| 威胁 | 缓解 | 剩余风险与响应 |
| --- | --- | --- |
| 提示注入要求原始坐标或脚本 | 意图编译拒绝坐标、速度、Shell、MAVLink；计划契约无这些字段 | 拒绝并记录 `policy_decision` |
| 模型提案越权 | DeepSeek 仅提出 JSON，必须与确定性模板结果一致 | 模型不可用时退化为确定性计划 |
| MCP 远程暴露或伪造调用 | 默认 `stdio`；远程仅回环 + SSH/认证网关 | 网关凭证和宿主机仍需按运维规范轮换 |
| 人工与智能体争抢控制 | 人工接管最高优先级；清除目标且禁止后续智能体指令 | 任务标为 `failed`，人工确认状态后重建 |
| PX4、导航桥、相机或服务异常 | 超时安全失败；服务重启把 `running` 转为 `interrupted` | 需要人工确认悬停/降落，旧任务不自动恢复 |
| 子智能体写入可执行文件 | 沙箱只允许五类审阅工件，禁止路径逃逸 | 宿主机文件权限仍由系统运维保护 |

## 人工审计点

人工批准是飞行前的强制步骤。任何未来会扩大模板、地标、飞行高度、任务区域、MCP transport 或接入真实硬件的变更，均必须经过代码审查和显式部署审批；不得由任务智能体自行修改安全策略。
