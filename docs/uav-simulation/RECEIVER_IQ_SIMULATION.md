# 低空频谱：协议先验、录制信号回放与实时接收

## 数据链

1. 从“无线协议识别”的不可变 SPEC 记录中，挑选已完成协议分析、具有明确采样率、质量合格且置信度达 0.8 的 IQ 选区。默认三源由两条 Wi-Fi 选区和一条 Bluetooth 选区组成，记录 ID、模型 ID、协议标签与置信度随实时帧返回。
2. 选区 IQ 以原采样率 62.5 MS/s 在内存中循环回放，先按均方幅度归一化，再用场景定义的发射功率驱动 Sionna RT 复数 CIR。各源保持选区中心频率相对 2412 MHz 接收机中心的频移。
3. 无人机机载接收机在 30/40 MHz 接收带宽内合成混合 IQ 和热噪声；地面端对每帧做 FFT、RSSI 和仿真真值 SINR。网页约每 0.5 秒请求一帧，返回 256 个按线性功率聚合的频谱箱，绘制最近 112 行瀑布图。单帧采样时长为 `FFT 点数 / 62.5 MS/s`，帧间有间隙，因此瀑布图代表定期快照，并不声称硬件连续采样。

## 重要边界

- SPEC 数据原本是接收设备录制的 IQ，含原采集信道和设备噪声；将它用作发射激励是**录制信号回放实验**，不是还原原始发射机。数据没有绝对功率校准，回放先归一化，输出的 dBm 来自声明的发射功率和接收机模型。
- 协议标签是原记录在“无线协议识别”页获得的**先验**。当前 1024–4096 点混合接收帧没有再次送入模型分类，界面不会将先验写成实时新识别结果。
- RSSI 来自混合 IQ 均方功率；SINR 以仿真可分离的目标源、其他源和热噪声功率计算。单靠混合 IQ 不能直接得知该真值。
- Sionna RT CIR 随无人机位姿采样更新；两个信道采样点之间，波形继续变化但信道使用最近的观测。没有模拟真实图传调度、硬件 ADC、上行丢包、频偏或运动多普勒。

## 存储与接口

`POST /api/uav-spectrum-sim/spectrum/receiver/frame` 返回当前帧的压缩功率谱、指标、观测时间和发射源先验；**不返回也不保存原始 IQ**。浏览器瀑布图只保留 112 行。原有单帧 `/spectrum/receiver/capture` 接口保留供诊断使用，实时界面不调用它。

每个与当前 Sionna CIR 位姿一致的接收帧，还会将其混合 RSSI 按 ENU 位姿写入独立的内存空间观测层。同一格的多帧先在线性功率域平均，再转换回 dBm。`GET /api/uav-spectrum-sim/spectrum/receiver/grid?layer_index=4` 返回该高度层的稀疏接收样本。低空仿真页仍只显示一张强度图：总功率图以 Sionna RT 传播补全为底，接收 RSSI 对实测格及附近约 11 m 范围做局部高斯残差校正，实测格显示接收值；单发射源图保持原 Sionna 结果。校正只作用于浏览器中的派生显示图，不覆盖或持久化原始传播网格。接收观测层最多保留 2048 个空间格、每格最长 1 小时，且不落盘。

Sionna 生成的观测目录只清理 `sionna_live_*` 和 `sionna_grid_*`：各自保留最近至少一条，最多 128/1024 条，并清理超过 24 小时的旧目录。后端启动时、此后每小时以及新观测累计到指定批次时执行清理。共享场景和无线协议识别原始记录不在清理范围内。实时网格持久化只保存恢复 REM 必需的发射源功率和位姿，不保存 CIR 或射线路径。
